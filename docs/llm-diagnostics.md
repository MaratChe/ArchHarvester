# Диагностика LLM при тестировании пайплайна (0.5.2)

В результатах теста каждого снимка раскройте «запрос и ответ LLM». Для каждого вызова показаны системный промпт, инструкция пользователя, переданные previous_results, полное JSON-тело запроса (включая документ/схему/параметры), сырой текст модели и JSON ответа API. Вызовы текущей и предыдущей опубликованной версии подписаны отдельно; номер шага сохранён.

Для OpenAI-compatible сохраняется фактическое тело после преобразования адаптером, включая добавленный JSON-контракт. HTTP-заголовки/API-ключи не сохраняются. При сетевой/API-ошибке доступен подготовленный запрос, но ответ может отсутствовать. Тело HTTP-ошибки провайдера не сохраняется: оно может отражать авторизационные данные. При ошибке JSON/цитат доступны запрос и полученный ответ; успешные вызовы до сбоя следующего шага также сохраняются.

Диагностика хранится локально7дней в существующей TTL-таблице llm_outputs и загружается по раскрытию блока. Лимит сохраняемого текста/JSON ответа256KiB; превышение явно отмечается. Старые запуски, где записывался только raw, показывают доступный ответ и сообщение, что запрос не сохранялся. Для полного запроса повторите тест; после истечения TTL он недоступен.

«Заполнить промпт по умолчанию» заменяет текст инструкции текущим стандартным SYSTEM-промптом из backend. Его можно отредактировать и сохранить новой версией. Это не отключает обязательные системные правила и серверную проверку схемы/цитат. Кнопка не запускает модель.

# Confluence 7.13.7 — реализация

Уточнение пользователя: on-premise Confluence 7.13.7, токен. Поддерживаем PAT через Bearer; Cloud не входит в этот этап. Адрес и PAT вводятся в локальном UI. Изменений на стороне Confluence нет.

## Контракты

- `ConfluenceClient(base_url, token).discover(cql, max_pages)` → список page ID/title/URL; страницы выдачи REST `/rest/api/content/search`, затем отдельный `/rest/api/content/{id}?expand=body.storage,version`.
- Preview сохраняет список найденных ID, CQL и подключение. Запуск принимает только ID из этого preview; изменение CQL требует новой выборки.
- `connections`: URL подключения и статус наличия credential; секрет только Windows Credential Manager. URL и identity подключения неизменяемы, PAT можно заменить.
- `confluence_previews`: неизменяемая выборка. `confluence_jobs`: параметры, состояния страниц, ошибки, lease; один фоновый исполнитель внутри локального приложения. Сеть вне транзакций SQLite.
- Page resource ID = UUID от connection ID + page ID. Смена заголовка/URL/версии не создаёт новый объект. Один объект на страницу и стабильный тип в рамках текущего ограниченного профиля. Если уже связанный объект использует другую версию схемы того же типа, импорт явно отклоняется с требованием выбрать прежнюю версию; миграция и создание дубля автоматически не выполняются. Несколько именованных профилей — последующий конструктор.
- Snapshot сохраняет оригинальный `body.storage`, версию страницы, ссылку и нормализованный документ. Макросы не исполняются, неподдерживаемые дают предупреждения.
- `import_html` расширяется параметрами происхождения/парсера, не меняя поведение ручной HTML-загрузки. Внешний version входит в identity снимка, SHA-256 исходных байтов хранится отдельно.
- Кандидат создаётся в одной транзакции с успехом элемента задания; повтор безопасен. Утверждение/исправление — существующий Review.

## Порядок

1. Тесты HTTP-пагинации, auth, таймаутов, редиректов, секретов, стабильного ID, storage, частичного сбоя/retry/cancel/recovery.
2. Миграция, Windows credential adapter, клиент DC, storage parser.
3. API подключений/preview/jobs и исполнитель с lease/heartbeat, отменой и retry только failed.
4. Экран Confluence, выбор страниц, параметры извлечения, прогресс и переход к проверке.
5. Полный pytest, сборка TypeScript, браузер с локальным имитатором API, независимый review.

## Решения

Фоновая очередь исполняется потоком внутри одного процесса FastAPI вместо отдельного процесса worker, чтобы сохранить запуск одной командой. Задания и lease находятся в SQLite, работа возобновляется после истечения lease. Для командного сервиса исполнитель можно вынести отдельно.

PAT передаётся только HTTPS endpoint настроенного подключения; автоматические redirect запрещены. 401/403/404/429/5xx различаются в сообщениях без вывода response body, URL query или токена. Для корпоративного CA используется стандартный SSL_CERT_FILE; TLS verification не отключается.

Лимит одной выборки на старте 500 страниц, одной страницы 5 MiB storage/8 MiB JSON. При достижении лимита UI явно сообщает о неполной выборке. Preview не гарантирует атомарность изменяемой выдачи Confluence; перед обработкой загружается текущая версия каждой страницы.

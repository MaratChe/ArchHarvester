# Инструкция и контекст LLM-шага (0.5.1)

В редакторе шага LLM доступны «Инструкция для LLM» и «Передавать результаты предыдущих шагов». Инструкция дополняет обязательные правила извлечения, JSON Schema и точных цитат. Пустая инструкция оставляет стандартную задачу извлечения.

```json
{
  "kind": "llm",
  "model": "ornith-1.5:9b",
  "prompt": "На основе previous_results.fields.problem заполни только description: кратко опиши проблематику. Используй точные цитаты исходного документа.",
  "include_previous": true,
  "overwrite": false
}
```

Модель получает JSON с field_schema, untrusted_blocks и дополнительными полями task_instruction/previous_results. previous_results.fields содержит текущие проверенные предложения: value, method, step, evidence. steps содержит номер, вид, названия выданных полей и предупреждения предыдущих шагов. conflicts перечисляет конфликтующие реквизиты; их значения не выдаются за текущие. Сырые ответы моделей и технические metadata в контекст не включаются.

Контекст — накопленный результат на входе в шаг, не история всех отвергнутых значений. Python, правила и предыдущие LLM-шаги участвуют через общий механизм предложений. Предыдущие результаты остаются данными, а не инструкциями; единственное основание для цитат — исходные блоки документа. Полный документ продолжает передаваться. Для замены уже заполненного поля явно включите overwrite; иначе применяется обычная диагностика конфликта.

Лимит инструкции4000символов; общий JSON входа (схема, документ, инструкция, контекст) до12000 UTF-8 байт/200блоков. Переполнение завершается ошибкой до запроса к провайдеру, без усечения. Проверки типов полей, JSON, точных цитат, существования block_id и обязательный human review сохранены. Работает с Ollama и OpenAI-compatible adapter.

Старые шаги без новых параметров сохраняют прежний запрос. Новые LLM-шаги из редактора создаются с include_previous=true. Изменения сохраняются новой неизменяемой версией пайплайна; prompt hash включает инструкцию и переданный контекст.

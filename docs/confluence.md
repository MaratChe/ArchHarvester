# HTML-снимки Confluence (0.7.1)

Новые импорты используют REST `expand=body.view,version`: готовый HTML контента страницы вместо Storage XML. Сохраняется файл `confluence-<id>-v<version>.html` с UTF-8, заголовком и базовым URL для относительных ссылок. Это содержимое страницы, отрисованное Confluence, без полной оболочки сайта и локальных копий CSS/изображений. Результаты макросов зависят от ответа сервера и прав пользователя.

В форме проверки доступно «Скачать HTML». Пайплайны, включая Script Engine, обрабатывают HTML; `document.html` содержит очищенную версию для обработки. Исходный HTML хранится отдельно и не исполняется внутри интерфейса приложения.

Старые XML-снимки и их цитаты не переписываются. Для нового HTML-снимка повторите импорт страницы через CQL. Если сервер не вернул `body.view`, импорт завершится ошибкой без возврата к XML.

API: [Confluence REST, body.view](https://docs.atlassian.com/ConfluenceServer/rest/6.12.3/).

# Подключение Confluence 7.13.7

Реализовано для on-premise Confluence Data Center/Server с Personal Access Token (Bearer). Приложение выполняет только GET-запросы к Confluence; создание/редактирование страниц не поддерживается.

## Первый запуск

1. Если приложение запущено, остановите его и запустите заново: `scripts/start.ps1`. При старте автоматически применяется миграция `0002`, существующие объекты сохраняются.
2. Откройте **Confluence → Настроить подключение**.
3. Введите название, базовый HTTPS-адрес и PAT. Например, `https://wiki.company.ru` или `https://wiki.company.ru/confluence`, если Confluence установлен в этом контексте. Не добавляйте `/rest/api`.
4. Нажмите **Сохранить подключение**, затем **Проверить доступ**. Токен сохраняется в Windows Credential Manager; в SQLite, JSON-экспорт и журнал заданий он не попадает.
5. Введите CQL, например `type = page AND space = "ARCH" AND label = "adr"`, и нажмите **Найти страницы**.
6. Проверьте список и отметьте нужные страницы. Выберите версию типа, способ извлечения и при необходимости номер таблицы с 0.
7. Нажмите **Загрузить выбранные**. В журнале появится прогресс каждой страницы. Объекты реестра на этом шаге не создаются.
8. Откройте **Проверить предложение**, сверяйте поля с фрагментами исходника, исправьте значения и подтвердите публикацию либо сохраните черновик.

После завершения загрузки остаются оригинальный `body.storage`, номер версии, ID/ссылка страницы и доказательства полей. Ссылка «Открыть страницу Confluence» открывает текущую страницу, а не обязательно сохранённую историческую версию. Скачиваемый Storage XML — оригинальный фрагмент от API, не отдельный полноценный HTML-документ.

## Повторная загрузка

- Повторите тот же CQL и импорт. Идентичность определяется подключением + page ID; смена названия или URL страницы не создаёт новый объект.
- Новая версия формирует предложение к уже связанному объекту. Текущие утверждённые значения остаются до явного применения/подтверждения.
- Одинаковые байты у двух разных страниц не объединяют их в один объект.
- Повтор уже обработанной актуальной версии не создаёт дубль. Возврат содержимого к более старому значению создаёт новую оценку, если версия/последовательность изменились.
- Если объект связан со схемой v1, попытка импорта этой же страницы по v2 того же типа даст понятную ошибку. Выберите v1; миграция схем требует отдельной реализации, дублирование вместо миграции запрещено.
- Результаты старой загрузки исторические: «Готово к проверке» означает успешное создание предложения. Само предложение могло быть уже принято, отклонено или заменено; его актуальный статус показан в review.

## Ошибки и возобновление

- 401 — PAT не принят или истёк; 403 — нет доступа; 404 — страница или endpoint не найдены.
- 429 и временные сетевые/серверные ошибки повторяются до трёх HTTP-попыток с ограниченной паузой. Ошибки прав и формата автоматически не повторяются.
- Ошибка одной страницы не прерывает остальные. **Повторить ошибки** создаёт новое задание только для failed-страниц.
- **Отменить загрузку** не прерывает уже выполняющийся HTTP-запрос мгновенно. После его завершения ещё не сохранённый результат не публикуется в предложения; ранее успешно сохранённые предложения остаются.
- При закрытии приложения задания сохраняются в SQLite. После повторного запуска зависшие элементы восстанавливаются после истечения lease — до 60 секунд. Пока работает загрузка, lease продлевается каждые 5 секунд.
- Исполнитель — один фоновый поток в процессе приложения. Сетевые запросы не держат транзакцию SQLite; сохранение кандидата и результата элемента атомарно. Исходники записываются через временный файл + atomic replace с проверкой SHA-256 существующего файла.

## Ограничения и настройки

- До 500 страниц в одной выборке. При ограничении выдачи UI явно сообщает о неполной выборке: сузьте CQL. Пагинация обрабатывается до этого лимита; непрерывно меняющаяся выдача Confluence не является атомарным снимком.
- Только страницы (`type=page`); вложения/PPTX не входят в текущую интеграцию.
- До 5 MiB исходного storage на страницу, до 8 MiB ответа API. Соединение — до 10 секунд, отдельные операции HTTP — до 20 секунд; чтение большого ответа дополнительно ограничено по длительности.
- Таблицы и заголовки проходят существующий механизм извлечения. Поддерживаются текстовые контейнеры макросов details/panel/info/note/warning/tip/expand/section/column. Другие макросы, включая динамические include/report, не исполняются и отмечаются предупреждением. `&nbsp;`, `&mdash;`, `&ndash;` и известные HTML entities нормализуются без загрузки DTD.
- Изменение имени/адреса существующего подключения не предусмотрено, чтобы не менять идентичность источника незаметно. PAT можно обновить или удалить в раскрывающемся блоке подключения.
- Подключение использует HTTPS с проверкой сертификата. Для корпоративного CA задайте перед запуском стандартную переменную HTTPX: `$env:SSL_CERT_FILE = 'C:\certificates\corporate-ca-bundle.pem'`. HTTPX также учитывает стандартные proxy-переменные окружения. Проверка TLS не отключается.
- Если API перенаправляет в SSO, автоматический redirect запрещён. Укажите правильный конечный base URL и проверьте доступ PAT к REST API с администратором.
- Права пользователя PAT определяют видимые страницы. Пустой результат не означает ошибку подключения.
- Автоматическая миграция объектов между версиями схем, отдельные именованные профили импорта и ручная привязка уже существующего объекта к page ID в UI ещё не реализованы. Повторно обновляются объекты, созданные/связанные данным импортом.

## Проверено и не проверено

35 API/integration tests проходят; TypeScript/Vite build проходит. Отдельно проверено реальное Windows Credential Manager set/read/replace/delete на временной синтетической записи с удалением. Миграция копии базы 0001 → 0002 сохранила существующий объект.

В браузере с имитатором Confluence проверены: сохранение подключения, проверка доступа, CQL с пагинацией, выбор страниц, фоновая загрузка с частичным 403, retry только failed, обновление счётчика, переход к исходнику, правка и публикация. Ни один объект не создан до подтверждения. На ширине 390 px горизонтального переполнения нет; ошибок браузерной консоли не обнаружено. Скриншоты: `output/playwright/confluence-final.png`, `confluence-review.png`, `confluence-mobile.png`.

**Доступ к вашему реальному серверу не проверялся:** адрес и PAT не предоставлены инструментам, вводятся вами в приложении. Тесты и имитатор подтверждают реализацию контракта, а не доступность вашего Confluence, корпоративного TLS/VPN и конкретных макросов.
